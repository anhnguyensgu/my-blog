## Before

I'm lucky to have seen the software industry evolve from coding by hand to agentic coding. I've been an engineer for a decade, starting out and growing into a senior at KMS Technology, and I'm still learning. That's enough selling myself.

Software engineering is more interesting than ever. The losers show up claiming AI is replacing their jobs, the winners share what they've built, and the scammers push FOMO, which reminds me of crypto. Here's how I actually work now.

I used to write every line myself. Slow, sure, but I understood all of it, because I had to think through each line to type it.

## After

Now I'm a father and I just don't have time to sit and type code. So I let the agent get the task done, then I review its shit.

And I do mean review. The first result is rarely the one I ship. I read the diff, find what's wrong or wasteful, and make it improve and optimize until it's actually good. The agent is fast. I'm the one who knows what good looks like.

## The Trap

> [!WARNING]
> AI without understanding the code is rotting your brain.

If you accept stuff you don't understand, you're not saving time, you're borrowing it. The first bug in code you can't read will cost more than everything you saved. And every time you skip the thinking, the skill you need to review gets a bit weaker.

## My Rule

Let the agent do the typing, never the understanding. If I can't explain a change, it doesn't get merged.
